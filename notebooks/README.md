# Notebooks

Exploratory analysis of the cohort and of the predictions. Outputs were stripped
before publishing (they contained patient images and data); run them against your
own data after configuring `configs/paths.yaml` and computing the feature tables
with `scripts/compute_features.py`.

No CSV is distributed with the repository: every table is patient-level data and is
read from / written to `<work_dir>` (see `configs/paths.example.yaml`).

## analysis/

| Notebook | Content |
|---|---|
| `01_demographics.ipynb` | Gender / age distribution at HUNT3 and HUNT4, correlations and clustering of the demographic features. |
| `02_cross_sectional_whole_brain.ipynb` | Brain parenchymal fraction (BPF) at HUNT3 / HUNT4: distributions, correlations, clustering. |
| `03_cross_sectional_tissue_based.ipynb` | Tissue volumes of each visit: distributions, correlations, clustering. |
| `04_longitudinal_whole_brain.ipynb` | HUNT3 -> HUNT4 change: BPF difference / ratio and NCC / SSIM / PSNR between visits. |
| `05_registration_whole_brain.ipynb` | Same as 04, comparing the HUNT3 image registered to HUNT4 with the real HUNT4. |
| `06_registration_tissue_based.ipynb` | Per-tissue Dice / volume change between the registered HUNT3 and HUNT4 segmentations. |
| `07_inter_patient_whole_brain.ipynb` | Inter-patient whole-image similarity (NCC, SSIM) at HUNT3 and HUNT4. |
| `08_inter_patient_tissue_based.ipynb` | Inter-patient tissue similarity (per-tissue Dice, volume difference). |
| `09_initial_macro_study.ipynb` | Joint study of demographic, longitudinal and cross-sectional features over the whole cohort. |
| `10_final_macro_study.ipynb` | Final comparison of the methods' predictions (BPF, Dice per tissue, image similarity) against HUNT3 / HUNT4. |
| `11_final_macro_study_diffusion_model.ipynb` | Same as 10 restricted to the patients predicted by the diffusion model. |
| `12_clustering_longitudinal_whole_brain.ipynb` | Clustering of patients by BPF change (writes the cluster assignment table). |
| `13_clustering_inter_patient_dbscan.ipynb` | DBSCAN clustering of the inter-patient similarity matrix. |
| `14_clustering_inter_patient_spectral.ipynb` | Spectral clustering of the inter-patient similarity matrix. |

## Tables the notebooks read

All under `<work_dir>/features/` unless stated otherwise.

| Table | Produced by | Used in |
|---|---|---|
| `demographic/demographic.csv` (`patient_id`, gender, ages, ...) | not generated by this repository: extracted from the HUNT spreadsheets | 01, 09 |
| `cross_sectional/whole_brain/whole_brains_stats.csv` | `compute_features.py cross_sectional_whole_brain` | 02, 10 |
| `cross_sectional/tissue_based/tissues_<n>/<id>.csv` | `compute_features.py cross_sectional_tissue` | 03, 09, 10, 11 |
| `longitudinal/whole_brain_based/whole_brains_stats.csv` | `compute_features.py longitudinal_whole_brain` | 04, 09, 10, 11, 12 |
| `longitudinal/tissue_based/tissues_<n>/<id>.csv` | `compute_features.py longitudinal_tissue` | 09, 10, 11 |
| `registration/whole_brain_based/whole_brains_stats.csv` | `compute_features.py registration_whole_brain` | 05, 10 |
| `registration/tissue_based/tissues_<n>/<id>.csv` | `compute_features.py registration_tissue` | 06, 10 |
| `inter_patient/whole_brain_based/features_hunt<h>/<id>.csv` | `compute_features.py inter_patient_whole_brain --hunt <h>` | 07 |
| `inter_patient/tissue_based/features_hunt<h>/tissues_<n>/<id>.csv` | `compute_features.py inter_patient_tissue` | 08, 13, 14 |
| `approaches/{whole_brain,tissue}_based/<method>/...` | `compute_features.py approaches_whole_brain` / `approaches_tissue` | 10, 11 |

Tables written by the notebooks (cluster assignments in `<work_dir>/clusters/`,
histograms data and `dice_mean.csv` in `<work_dir>/analysis/`) also contain
patient-level data and must not be committed. Figures are saved to `<results_dir>/figures/`.
