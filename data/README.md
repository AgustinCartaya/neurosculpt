# Data

This repository does not contain any imaging or patient data.

The thesis used longitudinal T1-weighted MRI from the HUNT Study (HUNT3 and HUNT4 visits).
HUNT data are only available through an application to the HUNT Research Centre
(https://www.ntnu.edu/hunt/data) and cannot be redistributed.

To run the code on your own longitudinal data, organise it as described in
[docs/data.md](../docs/data.md) and point `data_dir` in `configs/paths.yaml` to it.
